# Outreach Cadence — CTO Role Campaign

> Structured outreach process based on the target company research in `docs/target-companies-research.md` and `plans/target-companies-database.md`.

## Overview

This cadence defines a **4-week outreach cycle** for engaging target companies. Each company moves through defined stages with specific actions, timing, and tracking.

## Outreach Stages

| Stage | Description | Owner | Duration |
|-------|-------------|-------|----------|
| **Identify** | Company identified and validated against criteria | Self | Day 1 |
| **Research** | Deep-dive into company, leadership, tech stack, funding | Self | Days 1-3 |
| **Prepare** | Tailor CV/message to company context | Self | Days 3-4 |
| **Reach Out** | Send application/message via optimal channel | Self | Day 5 |
| **Follow-up 1** | First follow-up (if no response) | Self | Day 12 |
| **Follow-up 2** | Second follow-up (if still no response) | Self | Day 19 |
| **Connect** | Accepted connection / initial conversation | Self | Varies |
| **Interview** | Technical interview process underway | Self | Varies |
| **Offer** | Offer received | Self | Varies |
| **Closed** | Offer accepted or declined | Self | Varies |
| **Archived** | No response after all follow-ups, or explicitly rejected | Self | Day 26+ |

## Weekly Cadence

### Week 1 — Foundation
- **Monday**: Review target list, select 3 companies for the week
- **Monday-Wednesday**: Research each company deeply
- **Thursday**: Prepare tailored outreach materials
- **Friday**: Send initial outreach for all 3 companies

### Week 2 — Follow-ups & New Targets
- **Monday**: Follow-up on Week 1 companies that haven't responded
- **Tuesday-Friday**: Select and repeat the Week 1 process for 3 new companies

### Week 3 — Follow-ups & Continue
- **Monday**: Follow-up on Week 2 non-responders
- **Tuesday-Friday**: Select and outreach to 3 new companies

### Week 4 — Review & Archive
- **Monday**: Follow-up on Week 3 non-responders
- **Tuesday-Wednesday**: Review all pipeline. Archive cold contacts with no response.
- **Thursday-Friday**: Plan next month's targets based on learnings.

## Outreach Channels (in priority order)

| Priority | Channel | Best For | Notes |
|----------|---------|----------|-------|
| 1 | **Warm intro** (mutual connection) | All companies | Highest response rate. Check LinkedIn 2nd-degree connections. |
| 2 | **Direct application** (careers page) | Companies with posted CTO/Head of Eng roles | Follow application instructions precisely |
| 3 | **LinkedIn InMail** | Companies without posted roles | Keep under 200 characters, reference specific company context |
| 4 | **Email to founder/CTO** | Early-stage (Seed/Series A) | Use `first@company.com` patterns or Hunter.io |
| 5 | **AngelList/Wellfound** | Startups hiring on platform | Complete profile first |

## Message Templates

### Cold LinkedIn InMail Template

```
Hi {NAME},

I've been following {COMPANY}'s work in {SECTOR} — particularly {SPECIFIC_DETAIL_SHOWING_RESEARCH}.

I'm a full-stack engineer turned technical leader ({TECH_STACK}) exploring CTO/Head of Engineering opportunities. Would you be open to a brief chat about how I might contribute?

Best,
Sebastian
```

### Warm Intro Request Template

```
Hi {MUTUAL_CONNECTION},

Hope you're doing well! I'm exploring CTO/Head of Engineering opportunities and noticed you're connected with {TARGET_PERSON} at {TARGET_COMPANY}. 

Would you be comfortable making an intro? I've prepared a brief note about my background — happy to share it.

Thanks,
Sebastian
```

### Follow-up Template (Day 7)

```
Hi {NAME},

Following up on my previous message — I'd love to chat about how my experience with {SPECIFIC_EXPERIENCE} could help {COMPANY} with {CURRENT_CHALLENGE}.

Are you available for a 15-minute call this week?

Best,
Sebastian
```

## Per-Company Workflow

For each company, before outreach, complete:

- [ ] Read latest 3 blog posts / press releases
- [ ] Review LinkedIn for common connections
- [ ] Check Crunchbase/ PitchBook for latest funding
- [ ] Sign up for product trial (if B2B SaaS)
- [ ] Note current engineering challenges from job description
- [ ] Tailor CV to highlight relevant experience
- [ ] Prepare 3 talking points about why you're interested
- [ ] Send via best channel

## Tracking Fields

Each company entry in the CRM tracks:

| Field | Description |
|-------|-------------|
| `company` | Name |
| `sector` | E-commerce / Fintech / B2B SaaS |
| `stage` | Seed / Series A / B / C |
| `location` | HQ / Remote |
| `status` | Current stage from pipeline above |
| `priority` | 1 (high) / 2 (medium) / 3 (low) |
| `contact` | Person reached out to + title |
| `channel` | Outreach channel used |
| `outreachDate` | Date of first outreach |
| `lastFollowUp` | Date of last follow-up |
| `response` | Summary of any response |
| `nextAction` | What to do next |
| `notes` | General notes |
| `cvTailored` | Whether CV was customised |

## Success Metrics

| Metric | Weekly Target | Monthly Target |
|--------|--------------|----------------|
| New outreaches | 3 | 12 |
| Follow-ups sent | 3-6 | 12-24 |
| Conversations started | 1-2 | 4-8 |
| Interviews scheduled | 0-1 | 2-4 |
| Offers | — | 0-1 |

## Reflection & Iteration

End of each week, answer:

1. Which channels had the highest response rate?
2. Which stage/size of company responded best?
3. What messaging resonated?
4. What blockers came up?
5. Adjust next week's approach accordingly.
